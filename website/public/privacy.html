Privacy

This site collects one thing: the email address you give us when you join the LGTM Cloud waitlist, and the time you signed up.

We use it only to email you when LGTM Cloud opens. We don't share or sell it. There are no analytics or tracking scripts on this site, and fonts are served from this domain.

Signups are stored in a Cloudflare D1 database. Cloudflare hosts this site and processes requests to it.

To have your address removed, email hello@getlgtm.dev from that address and we'll delete it.

This covers getlgtm.dev only. The LGTM GitHub Action sends pull request content to the model provider you configure; see the README.
